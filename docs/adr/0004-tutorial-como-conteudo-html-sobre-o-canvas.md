# Tutorial como conteúdo HTML sobre o canvas

O tutorial "Como jogar" será renderizado como um overlay HTML/DOM por cima do canvas Phaser, e não como uma cena de jogo. Isso abre, de propósito, uma exceção ao ADR 0002: aquela decisão protege a **UI de jogo interativa** — o Ranking compartilha input, coordenadas e precisa parecer parte da partida —, mas o tutorial é **conteúdo estático de onboarding**, sem estado de jogo, visto uma ou duas vezes e praticamente nunca mais interagido, mais próximo de um manual (como o `regras.html`, que já é HTML) do que da interface do jogo. A fronteira passa a ser: **UI de jogo interativa = Phaser; conteúdo estático/onboarding = HTML/DOM**. O HTML/CSS entrega de forma barata o layout rico (o ciclo declarar→fazer→descontar, a escada de força que rotaciona no mobile, os naipes coloridos) que em Phaser exigiria posicionar cada objeto na mão e validar só no olho. A escolha permanece reversível: o overlay é isolado, não toca o core nem o sistema de cenas, e pode virar cena Phaser no futuro se a fronteira deixar de valer.
